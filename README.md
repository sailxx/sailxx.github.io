# sailxx.github.io

**Сайт [sailxx.github.io](https://sailxx.github.io/)** — главная страница с проектами sailxx

</div>

> [!NOTE]
> **Это сайт, а не программа.** GitHub публикует этот репозиторий как корень адреса `https://sailxx.github.io/`: главная страница, ссылки на проекты и служебные файлы для приложений и поисковиков.

> [!TIP]
> **Проекты на этом сайте**
> - **[Okto](https://sailxx.github.io/Okto/)** — планер, задачи, календарь и фокус. Работает на любом устройстве, для Android есть приложение с виджетом. Код: [sailxx/Okto](https://github.com/sailxx/Okto)
> - **[FITTER](https://sailxx.github.io/FITTER-AI/)** — Telegram-бот: сфотографируй еду, и ИИ посчитает калории и БЖУ

> [!IMPORTANT]
> **Служебные файлы — не удалять**
> - `.well-known/assetlinks.json` — подтверждает, что приложения Okto для Android принадлежат этому сайту: без него Okto открывается с полоской адреса, как в браузере
> - `.nojekyll` — без него GitHub Pages не публикует папку `.well-known`
> - `yandex_….html` — подтверждение сайта в Яндекс Вебмастере
> - `robots.txt` — правила для поисковых роботов

> [!WARNING]
> **Не переименовывайте репозиторий.** Корнем `sailxx.github.io` может быть только репозиторий с именем `sailxx.github.io`. После переименования сайт переедет на другой адрес, а `assetlinks.json` перестанет находиться — и Okto для Android потеряет подтверждение.
