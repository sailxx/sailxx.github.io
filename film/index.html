    Избранное

    Всё, что ты сохранил. Данные хранятся только в этом браузере.

    Рейтинги IMDb и постеры получены через OMDb API. Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB. Данные о доступности просмотра предоставлены JustWatch через TMDB.

    Источник данных

    Постеры, рейтинги IMDb и актёры уже встроены в каталог (источник — OMDb) и работают без ключа. TMDB нужен для раздела «Где посмотреть» и свежих описаний; без него вместо сервисов просмотра показывается «Информация о доступности сейчас не найдена».

    Чтобы подключить TMDB, вставь свой бесплатный ключ (API Read Access Token или API Key) из настроек TMDB. Ключ сохраняется только в localStorage этого браузера и отправляется только на api.themoviedb.org.
