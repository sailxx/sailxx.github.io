    Избранное

    Всё, что ты сохранил. Данные хранятся только в этом браузере.

    Постеры и рейтинги IMDb получены через OMDb API. Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB. Данные о доступности просмотра предоставлены JustWatch через TMDB.

    Источник данных

    Без ключа сайт работает в демонстрационном режиме: каталог, поиск по вайбу, фильтры и избранное доступны, но постеров, рейтингов и сервисов просмотра нет — мы не выдумываем эти данные.

    Чтобы подключить TMDB, вставь свой бесплатный ключ (API Read Access Token или API Key) из настроек TMDB. Ключ сохраняется только в localStorage этого браузера и отправляется только на api.themoviedb.org.
